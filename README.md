# Closed Logic

Site for closedlogic.com (renamed from After the Form, aftertheform.com, on 9 Oct 2026).

Marketing site. Next.js 16 (App Router), TypeScript, Tailwind 4. Built as a **static export** (`output: "export"`) and
hosted on **Cloudflare Workers static assets** (free plan). Every page is a plain file in `out/`; the only server code
is the form endpoint, `POST /api/request`, in `worker/index.ts`.

## Run locally

```bash
npm install                  # Node 22 (see .nvmrc; wrangler needs it)
cp .env.example .env.local   # values are optional locally
npm run dev                  # http://localhost:3000 (pages only: the form endpoint isn't part of next dev)
npm run cf:preview           # build, then serve out/ plus the Worker in the Workers runtime: http://localhost:8787
```

To try the form locally without sending anything, put `FORM_DRY_RUN=1` in `.dev.vars` (git-ignored). The Worker then
validates and builds both Sequenzy requests, returns success, and sends nothing. Never set it in production.

`npm run build` runs `scripts/check-placeholders.mjs` first and **fails while any placeholder remains**, then
`scripts/cf-postbuild.mjs`. The check is skipped only on preview builds: Cloudflare Workers Builds of any branch other
than `main` (`WORKERS_CI_BRANCH`) and Vercel previews (`VERCEL_ENV=preview`).

## Environment variables

| Name | Where | Purpose |
|---|---|---|
| `SEQUENZY_API_KEY` | Runtime **secret** on the Worker (dashboard: Worker > Settings > Variables and Secrets, or `npx wrangler secret put SEQUENZY_API_KEY`) | Used only by `worker/index.ts`. Without it the form shows its error state. |
| `SITE_INDEXABLE` | Build variable, optional | `1` makes a build indexable. Not needed on Workers Builds: the build of `main` is indexable automatically; every other build sends `noindex`. |
| `FORM_DRY_RUN` | `.dev.vars` only | Local testing, see above. |

## Hosting on Cloudflare

| Request | Served by | Runs code? |
|---|---|---|
| Pages (`/`, `/sample-report`, `/teardown`, `/privacy`, `/terms`), 404 page, `/_next/static/*`, `/_img/*`, icons, robots.txt, sitemap.xml, OG image | Workers static assets, from `out/` | No. Free, unlimited, not counted in the 100,000 Worker requests a day |
| `/api/*` | `worker/index.ts` (`run_worker_first: ["/api/*"]`) | Yes, only `POST /api/request` does work |

- Response headers for files: `out/_headers`, generated by `scripts/cf-postbuild.mjs` from `scripts/security-headers.mjs`
  (CSP, HSTS, caching, and `X-Robots-Tag: noindex` on every build except production).
- Images: pre-sized AVIF and WebP in `public/_img/` (`npm run images`), picked by `app/image-loader.ts`. No Images
  binding and no Cloudflare image transformations.
- Apex to www: a Cloudflare redirect rule (static exports can't redirect by host). See "Deploy" below.

| Command | What it does |
|---|---|
| `npm run build` | Placeholder check, `next build` into `out/`, then `out/_headers` |
| `npm run cf:preview` | Build and serve locally in the Workers runtime (http://localhost:8787) |
| `npm run cf:deploy` | Build and deploy (needs a logged-in wrangler; normally Workers Builds does this) |
| `npm run images` | Re-create the pre-sized AVIF and WebP files after adding or changing an image |

### Deploy (Workers Builds, connected to GitHub)

1. Cloudflare dashboard > Workers & Pages > Create > Import a repository: this repo.
2. Build command `npm run build`; deploy command `npx wrangler deploy`; non-production branch deploy command
   `npx wrangler versions upload`; production branch `main`. Node comes from `.nvmrc` (22).
3. Add the secret `SEQUENZY_API_KEY` (Settings > Variables and Secrets, type Secret).
4. Check a preview URL against the dev report's checks before connecting the domain.
5. Domain (zone on Cloudflare): Worker > Settings > Domains & Routes > Add Custom Domain: `www.closedlogic.com` and
   `closedlogic.com`. Then Rules > Redirect Rules > "Redirect from root to WWW" template (301, keep the path and query).
6. After the domain works on Cloudflare: remove the domains from the Vercel project, then delete or pause the Vercel project.

**Before the domain goes public, limit form submissions.** The Worker has no rate limiting of its own: a honeypot and a
`Sec-Fetch-Site` same-origin check are all `/api/request` does, and both are bypassable by a direct client. Add a
Cloudflare rate limiting rule on `POST /api/request` (Security > WAF > Rate limiting rules; for example 5 requests per
minute per IP), or add Turnstile to the form. Without one of those, anyone can post JSON straight to the endpoint and
spend the Sequenzy sending quota.

## Renaming

Brand name, domain, URL, email and legal lines live in `app/site.config.ts` and feed the copy, metadata,
JSON-LD, terms, privacy and the Worker. After a rename also:
- replace the artwork: `app/components/wordmark.tsx` (inline SVG), `app/icon.svg`, `app/apple-icon.png`, `app/favicon.ico`, `public/closedlogic-og-1200x630.png` and `public/closedlogic-og-x-1200x600.png` (all from Nova's files in `outreach/design/brand-closedlogic/`);
- `notifyTo` (form notifications) and the Sequenzy sender domain, once the new mailbox works;
- `app/booking.json` (both Cal.com links) and `site.config.ts` `linkedin` if those change; the Cal.com events themselves live in Cal.com;
- optional: `name` in `wrangler.jsonc` and `package.json` (the Worker name, not shown to visitors);
- the Sequenzy `source` attribute follows `site.domain`, so new leads carry the new domain.

## Pages and booking links

- `/` is for companies buying for themselves; `/agencies` and `/agencies/teardown` are for agencies.
- Both Cal.com links live in `app/booking.json`. Direct buttons link to `/book`, a 302 written to `out/_redirects` by `scripts/cf-postbuild.mjs`, so direct pages never show a Cal.com address. Agency buttons link straight to the agency URL.

## Tests and checks

- `npm run build` (or `npx next build` to skip the placeholder check): every route is static (`○`).
- `npx eslint .`, `npx tsc --noEmit`.
- `npm run cf:preview`, then open http://localhost:8787.
- Placeholder check on its own: `node scripts/check-placeholders.mjs`.
- `scripts/shots.mjs` (screenshots at four breakpoints) and `scripts/measure.mjs` (hero geometry at phone widths) are
  dev helpers using puppeteer-core and a local Chrome. Both take the base URL as an argument: `npm run dev` serves
  :3000, `npm run cf:preview` serves :8787. Set `CHROME_PATH` if Chrome isn't at the default Windows location.

## Notes

- Sequenzy custom attributes sent: `fullName`, `note`, `requestType`, `source`, `website`, plus `marketingHubTier` for check requests. Leads are not enrolled in sequences.
- No HubSpot tracking code: submissions go to Sequenzy, not HubSpot.
- Analytics: GA4 only, through the existing GTM container, loaded after the page load event. The CSP allows only the GA4 hosts.
